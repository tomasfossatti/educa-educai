# Prueba de carga: 60 estudiantes a la vez

2026-11-15 · Claude Code · `npm run test:load`

## Escenario

60 estudiantes sintéticos de una cátedra entran a la vez, abren la carpeta de la materia, hacen 3 preguntas en rondas simultáneas (todos envían al mismo tiempo) y cierran la conversación, lo que encola 60 análisis del motor. Cada estudiante usa su propio contexto de navegador sobre el build de producción.

La IA es el proveedor guionado con una demora simulada de 1500 ms por llamada, para que las conexiones queden abiertas como con el modelo real. La prueba mide la app y la base, no la API de Anthropic, que tiene sus propios límites por minuto.

Máquina: 4 CPU, 16 GB de RAM, Node v22.23.4. El servidor de la app corre limitado a 2 CPU (taskset 0,1), como una instancia chica; PostgreSQL y los navegadores usan el resto. Los 60 navegadores compiten por CPU entre sí, así que el tiempo total que ve cada estudiante es pesimista; los criterios se miden en el servidor. Duración total: 66 s.
